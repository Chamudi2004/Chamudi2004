I am a Computing and Information Systems undergraduate at Sabaragamuwa University of Sri Lanka, passionate about transforming complex problems into seamless, user-centric digital solutions.

My interests lie at the intersection of **mobile application development**, **frontend engineering**, **backend technologies**, and **data analysis**.

- 📱 **Mobile Development:** Building cross-platform applications using Flutter and Dart.
- 💻 **Frontend Development:** Creating responsive web interfaces using React.js, Tailwind CSS, HTML5, and CSS3.
- ⚙️ **Backend & Databases:** Working with Python, FastAPI, Firebase, Supabase, and SQL/NoSQL databases.
- 🌱 **Currently Exploring:** AI integrations, Gemini APIs, and real-time AIoT cloud architectures.
- 💬 **Ask me about:** Flutter, frontend development, UI/UX prototyping, and database integration.
